# Yari

Yari (`@mdn/yari`) is a source-only package for
[Fred](https://github.com/mdn/fred), the MDN Web Docs frontend.

Fred imports and bundles Yari's source for MDN Plus and the full Yari app for
offline support. Fred handles building and serving these features.

For frontend development and setup instructions, see the
[Fred repository](https://github.com/mdn/fred). To contribute to MDN's content,
see the [content repository](https://github.com/mdn/content).

## Dependencies

The package's `dependencies` provide libraries used by the source Fred consumes.
Legacy content-building tools, local servers, scripts, tests, and build tooling
are kept in `devDependencies` for working on this repository.
